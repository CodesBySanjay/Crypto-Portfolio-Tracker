# 💼 Crypto Portfolio Tracker - Portfolio Management (Boilerplate)

This is the initial setup for the **Portfolio Management** module in the Crypto Portfolio Tracker backend.

---

## ✅ Features Implemented So Far

- ✅ Basic REST Controller for crypto holdings
- ✅ Defined endpoints to:
  - Add a crypto holding
  - Get all holdings of the current user
  - Update a holding by ID
  - Delete a holding by ID

---

## 📁 Current File Structure

```
src/
├── controller/
│ └── PortfolioController.java
```
